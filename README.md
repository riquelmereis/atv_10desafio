# 🛒 Cadastro de Produtos - PHP & MySQL

Este projeto é uma aplicação web simples desenvolvida em PHP que permite realizar a validação e o cadastro de produtos numa base de dados MySQL.

---

## 📌 Funcionalidades

- **Formulário de Registo:** Permite a entrada de "Nome do Produto" e "Preço".
- **Validação de Dados em PHP:**
  - Verifica se o nome do produto não está vazio.
  - Verifica se o preço é um valor numérico maior que zero.
- **Feedback ao Utilizador:**
  - **Sucesso:** Exibe a mensagem *"Produto cadastrado com sucesso!"* após a inserção na base de dados.
  - **Erro:** Exibe mensagens claras caso os dados sejam inválidos (ex.: *"Erro: O preço deve ser um número positivo."*).

---

## 🛠️ Tecnologias Utilizadas

- **PHP** (Processamento do formulário e validação de dados)
- **MySQL / MariaDB** (Base de dados relacional)
- **HTML5 / CSS3** (Interface do formulário)
